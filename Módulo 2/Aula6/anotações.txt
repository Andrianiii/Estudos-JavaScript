Array inteiro
let jogos = [
    "Minecraft",
    "Forza",
    "GTA"
]

alert(jogos)

Resultado:

Minecraft,Forza,GTA

Um item específico
alert(jogos[1])

Resultado:

Forza

Quantidade de elementos
jogos.length

Resultado:

3

Criando objetos:
Objeto

Guarda características de uma coisa.

Exemplo:

let pessoa = {
    nome: "Miguel",
    idade: 19,
    cidade: "São Joaquim da Barra"
}

Acessando informações

Usamos:

objeto.propriedade

Exemplo:

pessoa.nome

Resultado:

Miguel

Diferença importante
Array
let frutas = [
    "Maçã",
    "Banana",
    "Laranja"
]

Acessa por posição:

frutas[0]
